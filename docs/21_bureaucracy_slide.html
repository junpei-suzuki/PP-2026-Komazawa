政策過程と官僚

復習：政策過程

Q.政策過程で官僚はどのような役割を果たしている？（WebClassチャット）

官僚 (bureaucrat)

役人。官吏。特に、政策決定に影響力をもつ中・上級の公務員。 （デジタル大辞泉）

  • 第一には、政治家が決定した政策を実施
  • しかし政策形成・決定にも影響
    • 例：日本の法案作成…官僚が立案した内閣提出法案が大多数

プリンシパル＝エージェント関係（次回）

本人ができないことを代理人に委任する関係

  • 本人＝政治家→代理人→官僚
  • 行政が関与する領域が増えるにつれて、官僚の専門知識はますます重要に

官僚の行動原理

復習：合理的選択理論

  • 経済学における基本的な考え
  • アクターは効用を最大化するべく行動と仮定

官僚も自己利益を追求する存在と捉えることが可能

  • 権力、収入、威信…
  • 二つのモデル：予算極大化モデルvs.組織形整モデル

予算極大化モデル

budget-maximizing model

官僚は自分の属する行政機関の予算を最大化させようと行動する

  • 予算→昇進機会、待遇改善、社会からの注目、有為な人材、大きな影響力…

批判：あまりにも単純すぎる

  • 必ずしも自己利益だけではない（→公益観）
  • 予算削減＝不利益というわけではない

組織形整モデル

bureau-shaping model

官僚が予算に対して持つ選好は地位によって異なり、予算極大化が直ちに実現されるわけではない

  • エリート官僚…予算よりは昇進の機会→自分にとって望ましい組織の形を作りたいし、予算削減に協力することで出世する機会も
  • 非エリート官僚…昇進の機会なし→予算極大化を選好、しかしフリーライダー問題にも直面

官僚の公益観

官僚の公益観

官僚は自己利益だけでなく「公益への奉仕」という義務感でも行動

シューバートの3類型

公益観 官僚の役割
合理主義 政治が決定 忠実な執行者
理想主義 官僚が定義 公益の実現者
現実主義 利害調整の結果 調整者・執行者

質問

合理主義・理想主義・現実主義という3つの公益像のうち、あなたはどの像を持った官僚が最も望ましいと思いますか。

理由も含めててチャットに書き込んでください

日本の官僚のタイプと変遷

日本の官僚は公益観に応じて3つのタイプが存在

  • 国士型官僚…理想主義的な官僚
    • 60年代まで主流
    • Cf. 城山三郎『官僚たちの夏』
  • 調整型官僚…現実主義的な官僚
    • 70年代以降に登場
    • 族議員や利益団体の登場・活発化に対応
  • 吏員型官僚…合理主義的な官僚
    • 80年代以降に登場
    • 自民党優位の確立と社会の成熟を背景

WebClassアンケートで回答

マックス・ヴェーバー

官僚制は社会の近代化にとって必要不可欠な合理的な存在と主張

  • 構成要素：規則による規律、明確な権限・ヒエラルキー、公私分離、文書主義、資格任用制、専業制
  • 特徴：統一的な意思決定、公平中立で予測可能な対応、強い持続性

ロバート・マートン

官僚制は逆機能をもたらし不効率になると指摘

  • 法規万能主義…法律・規則を絶対視し自己目的化
  • 繁文縟礼…規則が必要以上に細かくなる
  • セクショナリズム…縄張り争いと責任の押し付け合い
  • 権威主義…上位者が下位者を支配
